# 数学工具复用与整包压缩目标

[English](REUSE_COMPRESSION_OBJECTIVE.md) | [研究计划](RESEARCH_PLAN.zh-CN.md)

**当前状态（2026-10-29）：**本文件是当前阶段的研究入口，明确主问题、完整成本边界、选证规则、验收情形与停止条件。本阶段交付仅限文档定稿，不新增任务、计量入口、模型调用或实验预算。

## 主问题

在相同的背景库、原目标覆盖和正确性要求下，**把已有论证组织成可复用工具后，后续证明节省的空间能否抵消工具的完整引入成本？**

- **成功标准**：得到可信、可计算的比较结果，**不要求候选获胜**。压缩变小、持平、变大以及证据不足都是合法结论。
- **结论边界**：AI 使用效果与理解成本另列，没有专门证据时保持未知。
- **承接关系**：承接策略审查（[METHOD_REUSE_REVIEW.md](METHOD_REUSE_REVIEW.md)），并沿用 [METHOD_RESEARCH_DESIGN.md](METHOD_RESEARCH_DESIGN.md) 中的对象语义、正确性、原证保留和完整成本规则；历史试验计划不构成新的 API 调用额度。

## 比较对象与完整成本口径

比较两套具有相同目标覆盖的材料组合：

```text
D_A = K ∪ H_A ∪ Π_A
D_B = K ∪ P ∪ H_B ∪ Π_B
ΔC  = C(encode(D_A)) − C(encode(D_B))
```

| 符号 | 含义 |
| --- | --- |
| `K` | 共同背景：所列基础源码与原目标声明（相同 Lean 版本、允许公理与目标）。`Init` 与工具链等外部依赖固定版本并显式列出，不冒称已计入本地源码大小。 |
| `P` | 完整候选包：所有候选模块、定义、引理证明及继承模块按一次计费；即使只有少数或零个目标采用、或部分声明未被使用，也不免除 `P` 的成本。 |
| `H_A`、`H_B` | 各条件其余实际需要的辅助材料（实现、实例、存在性证书、桥接、指南、专用执行代码）。 |
| `Π_A`、`Π_B` | 按固定选证规则选出的完整证明源码。 |

### 计费与编码细则

1. **目标等价**：对象、参数、假设与结论须一致；重述须给出结构对应与回到原目标的核验桥接，任意 `iff` 不足以认证同一问题。推广范围另记，不得通过删题、改弱目标或增加公理获得压缩收益。
2. **去重与摊销**：重叠的继承模块按相同身份与精确源码只计一次；只有本次实际覆盖的目标可以分担成本，不得按假想未来用途摊销 `P`。
3. **编码与压缩器**：`encode` 沿用 [measure_compressed_reference.py](../scripts/measure_compressed_reference.py)——固定文档标签到精确 UTF-8 源码的规范 JSON，固定排序，保留名称、imports、注释与空白。
   - 主指标 `C`：`zlib`（level 9，`wbits=15`）的绝对字节数。
   - 敏感性检查：`bzip2`（level 9）。压缩率不作为主指标。
4. **整体序列化**：`D_A` 与 `D_B` 分别整体序列化和压缩，使基线中的重复文本获得同等压缩机会。同时报告包含 `K`（各边计一次）与排除 `K` 的非共享材料结果。压缩不满足可加性，不能代数抵消 `K` 或把单文件压缩字节相加。
5. **独立会话上下文**：独立会话中同名的 `Proof` 模块或 `Submission.solve` 使用预先固定的不同文档标签，避免覆盖并保留原源码与 imports。此类集合可重建独立证明上下文，但不自动构成可整体编译调用的单一 Lean 库。
6. **保留与分列**：原证、失败、较长候选、预算预约与收据全部保留；运行日志与研究档案不进入部署源码排名。共同基础设施、准备成本、生成用量与核验成本另列，未知量保持未知。

## 基线、选证规则与证据边界

- **基线准备**：沿用 [BASELINE_PREPARATION.md](BASELINE_PREPARATION.md)，在限定方法与预算内执行、记录并冻结旧工具整理。若需归因新包效果，冻结后两边须有匹配的继续搜索机会；历史搜索不明时只能作描述性成本比较。
- **严格缩短选证**：保留原有已核验证明；仅当原目标一致、核验通过且完整 `Proof` 源码 token 严格更少时替换当前所选证明，否则保留原证与原 imports。每题选证在压缩前固定，不得事后按压缩字节拼选有利组合。
- **模块化与依赖**：较长的模块化材料可作为完整计费的候选工具保留，不自动替换原证。命名引理依赖说明显式引用，内联证明同样合规；存在性证书支持逻辑推理，但不自动给出可求值的构造接口。
- **解释边界**：`ΔC > 0` 仅表示该固定材料与编码下的存储空间节省，**不能**推出 AI 更易理解、方法选择更好、数学更重要或未见任务迁移成立。

## 验收情形与停止规则

| 情形 | 判定要求 |
| --- | --- |
| 单证书短、整包大 | 保留逐题严格缩短结果，同时报告整包成本增加；不能只展示证明节省。 |
| 完整材料更小 | 在覆盖、来源、核验与计费均完整时，报告局部净存储收益与绝对字节差值。 |
| 漏桥接、漏包模块或删目标 | 比较不合格；缺失不得按零成本处理，不给完整组合优劣结论。 |
| 压缩器排序相反 | 同时保留 `zlib` 与 `bzip2` 结果，标明压缩器敏感，不宣称稳健优势。 |
| 载荷或运行时改变 | 严格回放报告变化；另存版本，不静默改写历史记录。解压须还原精确载荷。 |
| 生成或准备成本未知 | 字节可完整计算时仍可描述存储差异，但不声称总资源收益、基线充分准备或公平模型效果。 |

### 冻结与停止原则

- 正式比较前固定全部目标、包版本、来源清单、文档标签、排序、压缩器与运行时、选证规则及整理/搜索预算。
- 以全体目标结果为主；若展示累计前缀，须按原顺序全部报告，不得挑选有利子集。
- 完成固定比较即停止。零/负收益、压缩器敏感、覆盖不全或成本缺失均允许结案；不加题求胜、不靠重命名或换压缩器改善原分数，也不把开发题重新标为预留集。
